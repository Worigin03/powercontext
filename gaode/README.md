# 高德赛道 · 周边去哪儿

基于高德开放平台的地点推荐 Skill。用户说一句话（位置 + 想要什么 + 步行多久 + 要几家），Skill 驱动 Agent 调高德 MCP 查真实 POI、查真实步行路线，输出最多 3 条带数据依据的推荐。

## 交付物

| 文件 | 说明 |
| --- | --- |
| `SKILL.md` | 唯一提交物。可直接上传到提测平台的 Skill 文件 |

## Skill 的工作流

```
一句话需求
  └─ 拆槽位：起点坐标 / 城市 / 品类 / 步行上限 / 数量 / 排序偏好
       └─ maps_around_search   周边搜索（半径按步行上限折算）
            └─ 预筛：类型、同城、去重、直线距离排序取前 8
                 └─ maps_direction_walking  逐点查真实步行路线（并发）
                      └─ 硬过滤：步行分钟数 ≤ 上限
                           └─ 排序取前 3 → 表格 + 未核实声明
```

## 几个刻意的设计

- **距离口径只有一条**：回答里的步行距离/时间只能来自 `maps_direction_walking`，`maps_distance` 的直线距离仅用于挑选候选，不许出现在答案里。
- **单位陷阱前置**：高德步行 `duration` 是秒，Skill 里写死“÷60 向上取整”，避免 840 秒被写成 840 分钟。
- **预筛控调用量**：周边搜索可能返回 20+ 条，先按直线距离截到 8 条再查路线，避免单轮几百次 MCP 调用。
- **不满足就说不满足**：全部超时、路线失败、结果不足都有明确话术，且禁止用估算数字补位。
- **推荐理由只用可核实事实**：距离排名、类型匹配、所在道路；口味、环境、排队、评分一律标“未核实”，不编。
